DOT-MATRIX DISPLAY

5×7 glyphs drawn as dots, so each dot can animate. System voice only: states and numbers, never text that users wrote. Each display carries its real text as an accessible label.

BUTTONS

Blue is the only action colour. Red is reserved for irreversible organiser actions and always sits behind a typed confirmation. Machine animations play after the confirmation, never instead of it.

NOTICE PLATE

Carries mandatory wording word for word, at full contrast. Never small grey print.

Warning plate: credential-loss warning before claiming, and the identification warning beside every free-text field and before submitting.

WORKING STATE · LED CHASE

Replaces every spinner. Runs only while the app waits on something (the portal window, a submission). Idle machines stay still.

MOTION

  • 150–250 ms for UI feedback, 0.6–1.2 s for machine moments.
  • Light means something real happened: stamped, accepted, published.
  • Nothing moves in a way that hints at live counts or progress.
  • Reduced motion: jump straight to the final state.

ISOMETRIC LINE ART

  • 30° projection, 1px non-scaling strokes in #555555.
  • Three face fills: top #1c1c1c, front #151515, side #111111.
  • Named parts (stamp, lever, slot, display) so React can animate them.
  • Machines: Booth (response site), Press (portal), Vault (results).

BUILD RULES (SPEC §14)

  • CSS Modules + custom properties; no CSS-in-JS that injects style tags.
  • Vite assetsInlineLimit: 0, so no data: URIs.
  • Fonts bundled locally; this mockup loads them from Google Fonts only for preview.
  • Illustrations as React SVG components, never innerHTML.
